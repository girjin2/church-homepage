# 교회 홈페이지 V1

Vercel + Next.js + Supabase 기반의 교회 홈페이지 1차 완성본입니다.

## 들어 있는 기능
- 메인 홈페이지
- 교회소개
- 예배안내
- 설교 목록 / YouTube 연결
- 주보 PDF 목록
- 교회소식
- 오시는 길
- 모바일 / PC 반응형 디자인
- 관리자 이메일 로그인
- 관리자에서 교회 이름, 표어, 주소, 전화, 예배시간 변경
- 관리자에서 설교 등록/삭제
- 관리자에서 교회소식 등록/삭제
- 관리자에서 주보 PDF 업로드/삭제

## Supabase 연결 전
환경변수를 넣지 않아도 샘플 홈페이지가 열립니다. 관리자 쓰기 기능은 Supabase 연결 후 사용할 수 있습니다.

## 로컬 실행
1. Node.js 설치
2. 이 폴더에서 `npm install`
3. `npm run dev`
4. 브라우저에서 http://localhost:3000

자세한 실제 배포 순서는 DEPLOY_GUIDE_KO.md를 보세요.
